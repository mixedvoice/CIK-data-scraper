# Результаты выборов Госдумы 2026

Требования: Windows 10/11, [Python 3.10+](https://www.python.org/downloads/windows/), [Git](https://git-scm.com/install/windows).

#### Проверка версий установленных Python и Git
```powershell
python --version
```
```powershell
git --version
```

## Быстрый старт с GitHub

В PowerShell выполните команду для скачивания репозитория с GitHub. Дождитесь окончания загрузки.
```powershell
git clone https://github.com/mixedvoice/CIK-data-scraper.git
```

Запустите скрипт командой:
```powershell
python .\CIK-data-scraper\run.py
```
Если Git не установлен, на странице репозитория выберите **Code → Download ZIP**, распакуйте архив и выполните `python run.py` из распакованной папки.

При первом запуске `run.py` создаст окружение `.venv` и установит необходимые зависимости. Затем запустит скрипт и попросит ввести номер любой ОИК нужного региона, после чего начнется парсинг данных с сайта.

## Запуск из папки проекта

Перейдите в папку с проектом:

```powershell
cd .\CIK-data-scraper
```

Для запуска укажите любой номер ОИК нужного региона. Например,  `--oik 5` начнет парсинг для всего региона (Республика Башкортостан):

```powershell
python run.py --oik 5
```
Результаты парсинга сохраняются в Excel-файл "Результаты_2026.xlsx". 
Повторный запуск без параметра `--refresh` использует уже сохранённые дерево комиссий региона и протоколы результатов, формирует итоговый Excel-файл из них. При сбое или ошибке во время парсинга повторный запуск скрипта продолжит парсинг с места остановки. Excel-файл с результатами перезаписывается только после успешной обработки ВСЕХ выбранных комиссий. 

Для принудительного обновления данных с сайта (перезаписывает дерево комиссий и протоколы результатов):

```powershell
python run.py --oik 5 --refresh
```

Для тестирования работы скрипта используется параметр `--limit` N, который соберет первые N протоколов, включая ОИК, ТИК и УИК.
```powershell
python run.py --oik 5 --limit 4
```

## Параметры

| Параметр | Действие |
| --- | --- |
| `--oik N` | Выбрать регион по номеру N любой его ОИК |
| `--refresh` | Заново скачать дерево и протоколы с сайта   |
| `--export-only` | Собрать Excel-файл из завершённой сохранённой выгрузки |
| `--data-dir "C:/dir_path"` | Задать родительскую папку для сохранения данных по региону   |
| `--output "Name_of_file.xlsx"` | Задать имя  файла с результатами  |
| `--plain-progress` | Отключить цвет прогрессбара |
| `--limit N` | Собрать всё дерево, затем обработать первые N протоколов; Excel-файл помечается `_partial`|

## Сохранённые файлы

В папке проекта создаётся папка с названием выбранного региона:

```text
Республика Башкортостан/
    Результаты_2026.xlsx
    responses/        исходные ответы
    reports/          нормализованные протоколы
    tree.json         дерево комиссий
    plan.json         полный список комиссий
    collected.json    обработанные протоколы
    run.json          состояние загрузки
    errors.json       ошибки
```
В Excel-файле для протокола с результатами каждой комиссии есть ссылка на этот протокол на сайте ЦИК РФ.
